LEGACY IMPORT PIPELINE (2026-08-06)
====================================
FULL SUITE: 405 passed / 0 failed.

New module: companion/legacy_import.py (LegacyImportPipeline) + CLI
  (python -m companion.legacy_import --path ... [--dry-run] [--facts-only]).

Architecture contract honored: NO direct INSERT into facts. Flow:
  messages.jsonl -> parser (tolerant jsonl) -> store.log_message (sanitize,
  stable id msg_<sha1(ts|role|text)>, INSERT OR IGNORE) -> extract_fact_candidates
  (deterministic heuristics: user msgs, >=30 chars, importance>=5, chit-chat
  filter) -> store.add_fact (dedup -> ADMISSION GATE -> governor -> atomic txn
  -> FactCreatedEvent -> event journal -> FAISS embedding).

Two architectural holes found & FIXED (benefit all paths, not just import):
  1) add_fact had NO injection admission gate (only compress pipeline and
     add_belief checked). Added: injection-marked facts -> pending_review
     (kept, Iron Law #5, hidden from retrieval). This is the real Admission
     Controller the blueprint required on the canonical path.
  2) add_fact did not write memory_mutation_log. Added post-commit log_mutation
     (action=create) Ч provenance/audit for every creation.

Idempotency: stable fact id legacy_<sha1(text)[:16]> + existence check in
import_facts (dedup gate only sees active/dormant; a pending_embedding fact
would otherwise re-import). Re-run -> 'already_imported' (marker
legacy_import_done_v1 = sha256(file)).
